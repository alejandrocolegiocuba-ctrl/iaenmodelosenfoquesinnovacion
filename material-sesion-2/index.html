LO QUE COMPARTEN

Transformar información en números

El sistema codifica la entrada en representaciones numéricas. Usa patrones aprendidos durante el entrenamiento y realiza cálculos para producir una salida condicionada por tu petición.

Entrenamiento: aprende patrones ajustando sus parámetros con datos. Generación o inferencia: utiliza esos parámetros para responder. Escribir un prompt no equivale, por sí solo, a entrenar de nuevo el modelo.

LO QUE CAMBIA

La representación y el mecanismo

El texto puede producirse como una secuencia de tokens. Una imagen puede construirse refinando ruido. La voz y la música necesitan representaciones que puedan convertirse en ondas de sonido.

Estos son caminos representativos. Hay modelos de imagen que usan tokens y modelos de audio que usan difusión: las técnicas no pertenecen exclusivamente a una modalidad.

03 / ¿Y lo multimodal?

Una modalidad es una forma de representar información: texto, imagen, audio o vídeo. Un sistema multimodal trabaja con más de una de ellas en sus entradas, salidas o ambas.

Texto → texto usa una modalidad. Texto → imagen o texto → audio conecta modalidades diferentes. Una aplicación puede combinar varios modelos especializados o utilizar un modelo con capacidades integradas.

La interfaz puede parecer idéntica mientras el recorrido interno cambia.

Una petición, varias salidas

«Prepara un cuento ilustrado y narrado sobre la Luna».

Un recorrido posible: generar el cuento → usar sus descripciones para producir ilustraciones → convertir el relato en voz → reunir los resultados.

Compartir personajes, tono y contenido exige coordinación. No basta con crear cada parte por separado para que todo sea coherente.

¿Por qué el mismo prompt puede dar resultados diferentes?

La generación puede incluir azar: selección de tokens, ruido inicial u otros mecanismos de muestreo. También influyen el modelo, su configuración y el contexto. Por eso, una petición no siempre conduce a una única respuesta. Con ciertas configuraciones, la salida puede ser reproducible.

¿La IA busca una respuesta ya hecha?

En estos recorridos, el modelo genera contenido usando patrones aprendidos. Una aplicación puede añadir búsqueda web o consulta de documentos, pero eso es un componente adicional. Además, un modelo puede memorizar y reproducir fragmentos: generar no garantiza originalidad ni exactitud.

Glosario y fuentes para profundizar

Token: unidad codificada; en texto puede ser una palabra, parte de ella o un signo. Embedding: representación numérica de información. Latente: representación interna compacta. Prosodia: ritmo, acentos y entonación. Decodificador: componente que convierte una representación interna en una salida utilizable.

Los recorridos simplifican familias concretas de modelos; no describen todas las herramientas comerciales.
